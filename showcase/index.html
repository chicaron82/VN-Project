The Soul of Iteration

Philosophy

The Question: Agentic coding vs continuous iteration—which is better?

🤖 Agentic Approach

  • Set task, let AI execute autonomously
  • Efficient, hands-off, "set and forget"
  • Gets you to the destination
  • Optimized for speed and completion

💫 Iterative Riffing

  • Spontaneous ideas, mid-flight pivots
  • "What if we made it bougie?"
  • Sending it back to the kitchen for flavor
  • The Michelin treatment—soul included

The Truth: Both get you there. But only one feels alive. UV7 wasn't just built—it was crafted. Every "wait, what if..." moment added personality. Every "this needs more flavor" pivot made it premium. The Michelin treatment isn't about efficiency. It's about caring enough to iterate until it's perfect.

V1: The Prototype

🕸️ Spaghetti Dependencies

Systems called each other directly. A circular dependency nightmare where Tethers broke the Menu.

📄 Hardcoded Data

Dialogue, stats, and logical flags were buried inside JavaScript functions.

💣 Runtime Risks

"Trust me bro." No types. One typo in a variable name could crash the entire ending sequence.

🌍 Global State Chaos

State scattered across window.gameState, localStorage, and closure variables. No single source of truth.

📖 See Phase 4: StateManager

🎲 Manual Testing Only

"It works on my machine." No automated tests. Every change risked breaking something.

📖 See Phase 8: Testing

🏗️ Monolithic game-engine.js

2,000+ line god object. Everything in one file. Impossible to maintain.

📖 See Phase 7: Controllers

🐌 Direct DOM Manipulation

Constant reflows. No batching. Janky animations on older devices.

📖 See Phase 12: Performance

V2: The Rebuild

📡 Event-Driven Core

Decoupled systems via EventBus. Tethers just listen. Menus just listen. Zero direct dependencies.

📑 JSON Content

Pure separation of concerns. Narrative logic lives in strict JSON schemas, editable by writers.

🛡️ Strict Types

TypeScript caught 40+ potential crashes during migration. If it compiles, it runs.

🎯 Centralized StateManager

Single source of truth. Immutable state updates. Time-travel debugging ready.

📖 See Phase 4: StateManager

🧪 590 Automated Tests

Vitest + comprehensive coverage. Every feature tested. Confidence in every commit.

📖 See Phase 8: Testing

🏛️ Modular Controllers

Single responsibility. Each controller < 300 lines. Easy to understand and extend.

📖 See Phase 7: Controllers

⚡ Optimized Rendering

Batched updates. RequestAnimationFrame. Smooth 60fps on all devices.

📖 See Phase 12: Performance
V1: Event Handling (Callback Hell)
// Tightly coupled mess
function showMenu() {
    gameEngine.pauseDialogue();
    menuController.show();
    menuController.onClose = () => {
        gameEngine.resumeDialogue();
        if (gameEngine.currentScene) {
            gameEngine.currentScene.refresh();
        }
    };
}
V2: EventBus (Decoupled)
// Clean separation
EventBus.emit('menu:show');

// Elsewhere...
EventBus.on('menu:show', () => {
    DialogueController.pause();
});

EventBus.on('menu:close', () => {
    DialogueController.resume();
});
