1. **UV7 (United Voices 7)** - Mock studio brand/identity
2. **Version 848** - The actual visual novel game ("My Wife is in a coma... and in the code")
3. **V1 Build** - 50-day chaos speedrun using 8 AI collaborators
4. **V2 Rebuild** - Professional rewrite following best practices
5. **Showcase Evolution** - Documentation that became a full OS ecosystem

## Current Problems

- Visitors think UV7 = the game
- "Version 848" is barely mentioned
- Game premise (wife/coma/tamagotchi) never explained
- V1→V2→Showcase progression implied but not stated
- Meta-narrative (doc becoming OS) not connected to game's consciousness theme
