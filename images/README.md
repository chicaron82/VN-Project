# Images — Character Sprites

Tori's character sprites organized by emotional state.

## Sprite States

| Folder | Emotion |
| --- | --- |
| `Adored/` | Adored |
| `Clingy/` | Clingy |
| `Flirty/` | Flirty |
| `Grumpy/` | Grumpy |
| `Hangry/` | Hangry |
| `Happy/` | Happy |
| `Pouty/` | Pouty |
| `Sad/` | Sad |
| `Sleepy/` | Sleepy |
| `Snappy/` | Snappy |

Each folder contains variations of that sprite. Root-level `sprite_*.png` files are the default/thumbnail versions.

These sprites are preloaded by `AssetLoader.ts` and displayed by `SpriteController.ts`.
