# ToriGatchi

A Tamagotchi-style companion game featuring Tori. Runs as a standalone app and bridges to the main visual novel through the UV7 Shell.

## Structure

```
Tori-Gatchi/
├── index.html     # Entry point
├── style.css      # Styles
├── scripts/       # Game logic
└── images/        # Tori sprite assets
```

## Access

- **Standalone:** [chicaron82.github.io/ToriGatchi](https://chicaron82.github.io/ToriGatchi)
- **In-Shell:** Accessible via UV7 App Switcher
- **Gateway:** `ToriGatchiGateway.ts` in V2 bridges events between the games

## Achievement

Unlocking ToriGatchi earns the **"Pet Parent" 🐣** achievement in V2.
