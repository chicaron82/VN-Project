# Scripts

Build-time and utility scripts.

| Script | Purpose |
| --- | --- |
| `generate-stats.js` | Generates `showcase/stats.json` from codebase analysis |
| `generate-blog.ts` | Generates blog entries for the showcase timeline |
| `generate-lab-entries.ts` | Generates lab experiment entries |
| `generate-test-stubs.js` | Scaffolds test file boilerplate |
| `implement-tests.js` | Test implementation helper |
| `fix-test-mocks.js` | Fixes common test mock issues |
| `split-css.js` / `split-css-proper.js` | CSS splitting utilities |

## Usage

```bash
npm run stats                    # generate-stats.js
npm run generate:timeline        # generate-blog.ts
npm run generate:lab-entries     # generate-lab-entries.ts
```
