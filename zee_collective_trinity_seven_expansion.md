## **Note 34: CSSSpecificity_BugReport.txt**
**Location:** Act 2, Beat 6 (System Maintenance) - Developer debug logs  
**Author:** IZ

```
BUG REPORT: INLINE STYLE OVERRIDE ISSUE
═══════════════════════════════════════════════════

Found the pause menu bug!

CSS Specificity conflict:
- Inline styles (style="display: none") = 1000 points
- Class selectors (.active) = 10 points
- Inline ALWAYS wins

When restoreGameState() sets pauseMenu.style.display = 'none',
it creates an inline style that overrides .active class.

Solution: Clear inline styles, let classes handle visibility.

Change:
pauseMenu.style.display = 'none';

To:
pauseMenu.style.display = '';
pauseMenu.classList.remove('active');

Fresh eyes catch the details others miss.
That's what we're here for.

-IZ 🔍, Debug Analysis
CSS Specificity Wars: RESOLVED
```
