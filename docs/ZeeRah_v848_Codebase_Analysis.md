The player's timeline starts with **corrupted data from previous loops**. `[UNREADABLE]`, `[FRAGMENTED - TOO DEGRADED TO RECONSTRUCT]`. The narrative IS the save system.

### 2. Time Machine - Narrative Manipulation


The backlog isn't just history - it's a **time machine that the game can sabotage**:

- `lock()` - Some moments are locked forever
- `corrupt()` - Memory degradation affects your saves

### 3. Sensory System 2.0 - Accessibility as Architecture

```javascript
// Channel-based haptic/visual feedback
SENSORY_CUES = {
    // UI Channel - scales with comfort setting
    buttonPress: { channel: 'ui', duration: 30 },
    
    // Narrative Channel - scales with comfort setting
    toriHop: { channel: 'narrative', duration: 120 },
    
    // Critical Channel - NEVER SCALES (always full strength)
    denied: { channel: 'critical', duration: 150 },
    harshDenial: { channel: 'critical', duration: 200 }
}
```

Critical feedback (denial, warnings) is **immune to comfort settings**. The system respects accessibility while ensuring important cues are never missed.

### 4. INSANE Mode - Despair as Mechanics

```javascript
{
    name: 'INSANE',
    tetherCap: 66,           // Can NEVER reach full tether
    holdOnEnabled: false,    // No recovery button
    unlocked: false,         // Must complete INTENSE first
    permanent: true,         // Once chosen, CANNOT change
    decayRates: {

        medium: 0.15,

```

**The narrative theme of despair is mechanically enforced:**

- Tether cap at 66% = mechanical hopelessness
- Hold On disabled = no safety net
- Permanent commitment = inescapable consequences
- Time Machine read-only = no going back
