# Version 848: My Wife Is in a Coma... and in the Code

A narrative-driven interactive fiction experience built with vanilla JavaScript.

## About the Version Number

**"Why is it called Version 848? When is v849?"**

**There is no v849.**

848 is not a build number — it's the **loop iteration counter**.

In the story, Ronnie has used a modified Tamagotchi device to attempt saving Tori's consciousness from a coma. The device creates temporal loops, resetting the timeline each time it fails.

**847 attempts failed.**
**Version 848 is the first successful iteration.**

The "version number" is the body count of failed timelines. The title IS the lore. The number IS the narrative.

This is the bootstrap paradox in action: the device has been through the loop so many times that 848 is hardcoded into its very existence — from the code, to the UI, to the save system, to the meta-commentary itself.

### The Meta-Narrative

Every element of this game reinforces the loop concept:

- **Title**: "Version 848" — not a build, an attempt number
- **In-game counter**: Shows current loop iteration
- **Save system**: Tracks which timeline you're in
- **Secret codes**: Reveal the truth about 848
- **Code comments**: Explain why 848 can't be changed
- **The story itself**: About breaking free from loops

**This is the timeline where it finally worked.**

So no — we won't be releasing v849.

Because 848 is the loop that succeeded.

## Technical Details

### Built With
- Vanilla JavaScript (no frameworks)
- HTML5 / CSS3
- Local Storage for save system
- Responsive design (desktop + mobile)

### Key Features
- **Branching narrative** with multiple endings
- **Tether system** - Time-based connection mechanic
- **Save/Load system** - 6 save slots with auto-tracking
- **Secret codes** - Hidden unlockables and easter eggs
- **Mobile-optimized** - Touch controls and responsive layout
- **Skip system** - Unlockable after first completion
- **Notes collection** - Collectible lore fragments

### File Structure
```
v848/
├── vn-modular.html          # Main entry point
├── game-engine.js           # Core game logic
├── game-config.js           # Configuration constants
├── settings-manager.js      # Settings & codes system
├── save-manager.js          # Save/load functionality
├── tether-system.js         # Tether mechanic
├── cutscene-engine.js       # Cutscene animations
├── styles.css               # Main stylesheet
└── [route files]            # Story content
```

## Development

### Important Code Notes

⚠️ **Before modifying**: Read the comments in `game-engine.js` and `game-config.js` about VERSION 848.

The number 848 appears throughout the codebase. **DO NOT change it.** It's not a build number — it's integral to the narrative. Changing it will break:
- The story's meta-narrative
- Save file compatibility
- Loop counter logic
- Secret code rewards
- Credits sequences

**848 is sacred. It's the story.**

### Dev Commands (Mobile-Friendly)

Open Settings → Secret Codes and enter:

```
devhelp     - Show all dev commands
clearnotes  - Clear collected notes
reset848    - Reset to VERSION 848
unlockskip  - Unlock skip feature
revealcodes - Reveal all secret codes
```

See `DEV-COMMANDS.md` for full list.
