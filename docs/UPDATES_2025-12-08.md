### 2. Tether Decaying While Game Paused

**Issue:** Tether continued to decay when player opened settings menu or notes viewer, causing unfair deaths during reading.

**Root Cause:**

- Settings menu and notes viewer didn't call `stopDecay()` on the tether system
- Only the tether's passive decay timer needed pausing, not the entire game

**Fix Applied:**

**Settings Menu** ([game-engine.js:4417-4420](../system/game-engine.js#L4417-L4420)):

```javascript
showSettings() {
    // DIZEE FIX: Stop tether decay while in settings
    if (this.currentRoute && this.currentRoute.tetherSystem) {
        this.currentRoute.tetherSystem.stopDecay();
    }
    // ...
}

closeSettings() {
    // ...
    // DIZEE FIX: Resume tether decay when closing settings
    if (this.currentRoute && this.currentRoute.tetherSystem) {
        this.currentRoute.tetherSystem.startDecay();
    }
}
```

**Notes Viewer** ([collectibles-manager.js:515-518, 638-641](../system/collectibles-manager.js)):

```javascript
showNotesViewer() {
    // DIZEE FIX: Stop tether decay while viewing notes
    if (this.route && this.route.tetherSystem) {
        this.route.tetherSystem.stopDecay();
    }
    // ...
}

hideNotesViewer() {
    // ...
    // DIZEE FIX: Resume tether decay when closing notes
    if (this.route && this.route.tetherSystem) {
        this.route.tetherSystem.startDecay();
    }
}
```

**Result:** Tether now pauses during:

- Settings menu
- Notes viewer (in-game)
- Resumes when closing either

**Files Modified:**

- `system/game-engine.js` (lines 4417-4420, 4436-4439)

### 4. VERSION 848 [FINAL] Persisting After Retry

**Issue:**

1. Player completes true ending → "VERSION 848 [FINAL]" appears
2. Player returns to menu and starts new route
3. Player gets bad ending on retry
4. Main menu still shows "VERSION 848 [FINAL]" instead of "VERSION 849"

**Root Cause:**

- `loopStatus` was set to `'succeeded'` after true ending
- When starting a new route, `loopStatus` wasn't reset to `'attempting'`
- Version incremented to 849, but status still showed as succeeded

**Fix Applied** ([game-engine.js:2005-2011](../system/game-engine.js#L2005-L2011)):

```javascript
startRoute(routeName) {
    // Clear sprites before starting route
    this.clearAllSprites();

    // DIZEE FIX: Reset loop status to 'attempting' when starting new route
    // This prevents [FINAL] from persisting after true ending -> retry -> bad ending
    if (this.loopStatus === 'succeeded' || this.loopStatus === 'accepted') {
        const previousStatus = this.loopStatus;
        this.incrementVersion(); // Increment version for new attempt (also resets status)
        console.log(`🔄 New attempt after ${previousStatus} - VERSION ${this.loopVersion}`);
    }
    // ...
}
```

**Result:**

- True ending: "VERSION 848 [FINAL]" ✅
- Return to menu and retry: Auto-increments to "VERSION 849" ✅
- Bad ending on retry: Shows "VERSION 849" (red glitch, no [FINAL]) ✅

**Files Modified:**

- `system/game-engine.js` (lines 2005-2011)

### 5. Skip Button Jumping on Logo Animation

**Issue:** The "SKIP" button on the UV7 splash screen jumped position when clicked or focused.

**Root Cause:**

- Overrode skip button's `position: absolute`
- Same issue previously fixed for close buttons

```css
}
```

**Result:** Skip button stays in place when clicked, no jumping.

### 6. Internal Thought Bubbles Not Scrollable

**Issue:**

- Ronnie's opening scene has long internal thought text
- Scrollbar appeared but couldn't actually scroll
- Unable to read full content

**Root Cause:** Base `.internal-bubble` style had:

1. `pointer-events: none` - prevented ALL mouse/touch interaction (including scrolling)
2. No `max-height` - text overflowed without bounds
3. No `overflow-y` - no scrollbar mechanism

Mobile variants correctly overrode these, but desktop didn't.

**Fix Applied** ([styles.css:3610-3620](../styles.css#L3610-L3620)):

```css
.internal-bubble {
    /* ... existing styles ... */
    max-height: 40vh; /* DIZEE FIX: Limit height to allow scrolling for long text */
    pointer-events: auto; /* DIZEE FIX: Enable pointer events for scrolling */
    overflow-y: auto; /* DIZEE FIX: Enable vertical scrolling */
    overflow-x: hidden; /* DIZEE FIX: Prevent horizontal overflow */
    word-wrap: break-word; /* DIZEE FIX: Wrap long words */
    -webkit-overflow-scrolling: touch; /* DIZEE FIX: Smooth iOS scrolling */
    scroll-behavior: smooth;
    /* ... */
}
```

**Trade-off:**

- With `pointer-events: auto`, clicking directly on bubble won't advance dialogue
- User must click outside bubble to advance
- This is acceptable because:
  - Users need to read/scroll bubble content anyway
  - Bubbles positioned away from main dialogue area
  - Most of screen still clickable

**Result:** Internal bubbles now fully scrollable on all screen sizes.

**Files Modified:**

- `styles.css` (lines 3610-3620)
