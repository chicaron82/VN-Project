## 🔧 TROUBLESHOOTING

### **"Files don't load"**
- ✅ Verify all 7 files in same folder
- ✅ Check file names match exactly (case-sensitive)
- ✅ Make sure images have .png extension

### **"Menu background doesn't show"**
- Not a bug - images may take a moment to load
- Or images couldn't be loaded (game still works!)

### **"Tether doesn't change based on Ronnie's choice"**
- Did you play Ronnie's route first?
- Did you reach Act 2 and make the choice?
- Try clearing browser cache and replaying

### **"Cross-route bridge not working"**
- Check browser console (F12)
- Verify localStorage is enabled
- Make sure you're using updated tori-route.js
