=====================================

STEP 1: Add HTML to vn-modular.html

- Backlog Screen: After Settings Menu

STEP 2: Add CSS to styles.css
------------------------------
Copy the entire contents of settings-backlog-styles.css and paste at the END of styles.css

STEP 3: Add JavaScript to vn-modular.html
------------------------------------------
Add this script tag BEFORE the existing game scripts (after game-config.js):
<script src="settings-manager.js"></script>

STEP 4: Initialize in game-engine.js constructor
-------------------------------------------------
In GameEngine constructor (around line 50), add:

        // Settings and Backlog Managers
        this.settingsManager = new SettingsManager(this);
        this.backlogManager = new BacklogManager(this);

STEP 5: Update typewriterText method in game-engine.js
-------------------------------------------------------
Find the typewriterText method and update the delay calculation:

    typewriterText(element, text, callback, internalLength = 0) {
        // Use settings manager for delay
        const delay = this.settingsManager.getTypewriterDelay();
        
        // If instant mode, show all text immediately
        if (delay === 0) {
            element.textContent = text;
            if (callback) callback();
            
            // Start auto-advance if enabled
            this.settingsManager.startAutoAdvance(() => {
                if (this.currentScene && this.currentScene.next) {
                    this.currentScene.next();
                }
            });
            return;
        }
        
        // Rest of existing typewriter logic...
        // At the END of typewriter completion, add:
        
        // Start auto-advance timer when dialogue finishes
        this.settingsManager.startAutoAdvance(() => {
            if (this.currentScene && this.currentScene.next) {
                this.currentScene.next();
            }
        });
    }

STEP 6: Add backlog tracking in displayScene
---------------------------------------------
In displayScene method, after setting dialogue text (around line 530), add:

        // Add to backlog
        if (scene.dialogue) {
            this.backlogManager.addEntry(scene.character, scene.dialogue);
        }

STEP 7: Add settings/backlog methods to GameEngine
---------------------------------------------------
Add these methods at the end of GameEngine class:

    // ========================================
    // SETTINGS MENU
    // ========================================
    
    showSettings() {
        const settingsMenu = document.getElementById('settings-menu');
        if (settingsMenu) {
            settingsMenu.style.display = 'flex';
            this.isPaused = true;
        }
    }
    
    closeSettings() {
        const settingsMenu = document.getElementById('settings-menu');
        if (settingsMenu) {
            settingsMenu.style.display = 'none';
            this.isPaused = false;
        }
    }
    
    resetSettings() {
        if (confirm('Reset all settings to default?')) {
            this.settingsManager.resetSettings();
        }
    }
    
    // ========================================
    // DIALOGUE BACKLOG
    // ========================================
    
    openBacklog() {
        const backlogScreen = document.getElementById('backlog-screen');
        if (backlogScreen) {
            this.backlogManager.render();
            backlogScreen.style.display = 'block';
            this.isPaused = true;
        }
    }
    
    closeBacklog() {
        const backlogScreen = document.getElementById('backlog-screen');
        if (backlogScreen) {
            backlogScreen.style.display = 'none';
            this.isPaused = false;
        }
    }
    
    // Show/hide backlog button during gameplay
    toggleBacklogButton(show) {
        const backlogBtn = document.getElementById('backlog-button');
        if (backlogBtn) {
            backlogBtn.style.display = show ? 'block' : 'none';
        }
    }

STEP 8: Add Settings button to Main Menu
-----------------------------------------
In vn-modular.html main menu section (around line 110), add:

<button class="menu-button" onclick="game.showSettings()">SETTINGS</button>

And add to Pause Menu (around line 196):

<button class="pause-menu-button" onclick="game.showSettings()">SETTINGS</button>

STEP 9: Show backlog button during gameplay
--------------------------------------------
In startRoute() method, add:

        this.toggleBacklogButton(true);

And in returnToMainMenu(), add:

        this.toggleBacklogButton(false);

STEP 10: Handle auto-advance cancellation on click
---------------------------------------------------
In the dialogue box click handler, add:

        // Cancel auto-advance when user clicks
        this.settingsManager.cancelAutoAdvance();

That's it! Settings and Backlog fully integrated! 🎉
